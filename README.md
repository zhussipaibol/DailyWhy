# Апория

«Апория» — по-гречески «безвыходность»: вопрос, в котором логика заводит в тупик. Каждый день здесь появляется один глубокий вопрос о математике, разуме, реальности, знании, жизни и обществе — и подробный разбор: история идей, главные позиции, эксперименты и то, чего пока никто не знает.

Сайт: https://zhussipaibol.github.io/DailyWhy/

## Как устроено

- `index.html`, `assets/` — сам сайт: одна страница, без сборки.
- `posts/*.md` — выпуски в Markdown.
- `posts/index.json` — список выпусков для главной страницы и архива.
- `queue.md` — очередь вопросов. Допиши сюда свой, и он попадёт в один из ближайших выпусков.
- `GUIDE.md` — правила, по которым пишутся выпуски.

Новый выпуск добавляется автоматически каждое утро в 8:00 по Астане.

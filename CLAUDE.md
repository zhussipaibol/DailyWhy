# Апория — заметки для Claude

Это статический сайт на GitHub Pages с ежедневными выпусками на русском языке: один глубокий, абстрактный вопрос в день (математика, сознание, физика, знание, жизнь, общество, философия).

Если задача — написать или добавить выпуск, следуй `GUIDE.md` полностью: там порядок работы, темы по дням недели, структура, стиль и формат файла.

Не меняй `index.html` и `assets/` во время ежедневного выпуска, если тебя об этом прямо не попросили.
